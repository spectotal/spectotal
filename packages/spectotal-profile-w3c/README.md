# @spectotal/profile-w3c

W3C/ReSpec profile package for Spectotal.

## Exports

- `w3cProfile`: parser + postprocess profile for `@spectotal/core`
- `w3cLintRules`, `w3cRecommendedLintConfig`, `createW3cLinter`
- W3C patch helpers:
  - `createWrapNormativeParagraphRecipe`
  - `wrapNormativeParagraphsInDocument`
  - `wrapNormativeParagraphsInWorkspace`
  - `createW3cPostprocessAdapter`
